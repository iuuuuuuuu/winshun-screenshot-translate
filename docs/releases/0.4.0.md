# 截图翻译 0.4.0：原生版，无需 Python

本次从 0.3.3 升级为 C++ / Qt Quick 原生版。安装包自带运行库，使用前不需要安装 Python、PySide6 或 Qt。

## 这次更新了什么

- 补齐剪贴板翻译、划词翻译和鼠标指词 OCR，均在鼠标或选区附近显示小窗。
- 修复管理员 Codex 等软件无法划词的问题：允许插件跟随 WinShun 的管理员权限运行。
- 原文默认可编辑；Enter 重新翻译，Shift+Enter 换行。保留原来的正文样式，聚焦只显示文字光标。
- 固定小窗后可跟随新的选区；修复拖动后背景、操作按钮消失，以及点“重试”窗口不断下移的问题。
- 改进鼠标 OCR 对短句、换行、小字号英文及中英文混排的识别，减少单词被拆开和只识别到句首的问题。
- 优化多屏框选、拖动和关闭响应，恢复随选区大小调整的加载动画。
- 保留十个翻译渠道、一键测试、上下双语对照，以及可记忆、可配置恢复时间的自动降级。

## 安装要求

**Windows 10/11 x64、WinShun 0.22.0+、系统 OCR 语言包。**

下载 `iuuuuuuuu.screenshot-translate-0.4.0.wsplugin`，在 WinShun 设置 → 插件 → 从压缩包安装。旧渠道、密钥、代理和自定义热键继续保留。

本版按官方新规则作为“未审核的原生插件”提交，首次安装及每次更新需确认。此标记说明审核状态，不是安全认证；官方库更新以 PR 合并为准。

## 管理员软件如何划词

从托盘彻底退出 WinShun，再以管理员身份启动。在设置 → 插件 → 截图翻译中允许新增权限，并按卡片提示点击“确认”。出现管理员盾牌后，返回目标软件选中文字，再按划词热键。

默认快捷键：截图 Alt+Shift+T；剪贴板 Alt+Shift+C；划词 Alt+Shift+W；鼠标 OCR Alt+Shift+O。原来已自定义或清空的设置继续优先。

已完成普通权限、管理员权限及独立 Chromium 选区测试；使用者已确认管理员 Codex 的划词恢复可用。独立运行库包另外检查加载来源和界面回归。安装包内附源码提交记录、运行库许可与依赖清单，附件提供 SHA-256 校验值。

免费翻译服务可能限流，OCR 对模糊、小字号和复杂排版仍可能识别不准；可以直接修改原文后重新翻译。付费渠道只做本地协议测试。
